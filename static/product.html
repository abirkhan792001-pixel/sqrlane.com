01 One booking

Watch one booking change, field by field.

A strike is called at the Port of Hamburg. Three agents take their turn on a booking bound for it, and each one’s work is a change on the record — not a message beside it. The fourth turn is yours.

HoverTap any agent’s line to see why.

From one recorded run of the demo’s Hamburg scenario, with the model switched off so the page stays the same run to run — the lines above are the rules engine’s own. On the live demo the Routing and Comms Workers write the same fields in the model’s words. The booking is synthetic; the TMS behind it is a demo connector, and nothing is ever written.

02 Two layers, one book

The risk half decides. The desk carries it out.

A reroute is not finished when it is decided. The booking has to be amended, a new port can move the customs entry, and whatever the customer is told has to meet their standing instructions. The Routing Worker hands each of those to the everyday desk — as messages, on the same booking.
